# Audio Directory

You can place your own MP3 / M4A songs here (for example `romantic-track.mp3`).
To change or add songs, edit `src/data/birthdayData.ts` under `birthdayData.music.tracks`.

The website automatically includes a rich Web Audio API harmonic romantic melody generator, so the music player will play beautiful romantic lo-fi melodies out of the box even without any external mp3 files!
